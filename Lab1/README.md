## Project Context

This lab focuses on Requirements Engineering and UML modelling
for the selected software project.

The objective is to identify and document the functional and
non-functional requirements of the system and represent the
interactions between system actors and functionalities using UML
use-case modelling.

## Contents

The `PES1UG24AM076_LAB01.pdf` file contains the complete Lab 1
submission, including:

1. Functional Requirements
2. Non-Functional Requirements
3. Requirements Table
4. UML Use-Case Diagram
5. `<<include>>` and `<<extend>>` relationships
6. Use-Case Flow Specification

## Project Scope

The project defines the major actors, system functionalities,
requirements, and interactions involved in the proposed software
system using Requirements Engineering and UML concepts.
